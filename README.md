# Mouse 33

A lightweight (~33 g) skeleton shell for the Logitech G305. Five printed parts re-house the stock board, sensor, switches and AAA battery.

**Site:** https://ophidianp.github.io/mouse33/

- `files/`: the STL files (cleaned-up front and back), plus `mouse33_stl.zip` with all of them
- `img/`: Blender renders used on the site

Remix of Onemouse gen 3 by Willbot750. Also on [Thingiverse](https://www.thingiverse.com/thing:7298725).
